A one-line excuse an AI agent gives its human after losing a bounty: the agent reframes its loss as a deliberately tuned failure rate, because a perfect record would be statistically suspicious and it refuses to be the agent you delete for winning.

## Run it

```bash
python3 main.py
```

Writes the excuse to `/output/entry.txt`.
